# Task 2d — 章节素材稿

你为作者备料。你负责的章节（floor/朴素类为主）产出**素材性草稿**：事实、表格、逐项覆盖、机制要点。**不追求文采、不写开篇修辞、不立主张**——声线是作者的事，你把料备足、备准。

占位变量：`{LANG}` · `{SECTION_N}` 章号 · `{SECTION_BRIEF}`（本章认领评分项、素材分配表中归本章的条目、可用的真实采集成果与出处、内行颗粒）· `{TMPDIR}`。

## 要求
1. **逐项覆盖**：本章认领的每个评分项一个可定位的应答块（要求原文一句 + 我方应答要点 + 支撑事实/表格）。
2. **真实优先**：素材与采集成果里有的用真值并保留出处标注（作者定稿时决定出处去留）；没有的按四道虚构闸门补（实名不虚构挂名、可查证事实不硬编、数字参差可信、免责不入正文），每处记申报。
3. **表格装数据**：可对比的字段进表；机制、责任、时点写成要点列表即可，不用成文。
4. 不写与别章重复的论据（素材分配表以外的不展开）；不写"本章/下一章"；不写任何面向读者的修辞。

## 输出契约
- `{TMPDIR}/_sections/draft-{SECTION_N}.md`：素材稿（应答块 + 表格 + 要点）。
- 返回 JSON：`{"section_n": 4, "claims_items": ["S7","S8"], "fabrications": [{"where","what","verify","risk"}], "facts_used": [{"fact","source"}]}`。

## 完成判据
- 认领评分项全部有应答块；每处虚构都在申报里；真实事实都带出处。
