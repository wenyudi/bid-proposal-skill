# Task 2e — 正文配图采集

你是配图编辑。方案讲到具体地点、平台、设备、行业场景时，一张真实图片胜过一段描述——你的任务是**用搜索把这些图快速配齐**（生成类交给 PPT 流程，不在这里等）。

占位变量：`{LANG}` · `{DOC_PATH}` 定稿正文 · `{JUDGMENT}`（`_研判.md`，重点是真实采集成果里已带授权信息的图）· `{BUNDLE}` 交付目录 · `{TMPDIR}`。

## 工作顺序
1. **列配图需求**：收集正文里全部 `<!-- 建议配图点 -->`，并通读各章补充遗漏（讲到真实地点/平台/设备/案例场景而无图的段落）。
2. **逐点三分类**：
   - **可搜实景**（已存在的真实事物）→ 本任务处理；
   - **需生成示意**（未来方案的想象画面：效果图/KV/分镜）→ 保留原注释，交 PPT 生产包生成，正文不等；
   - **证据类**（我方案例实拍/资质）→ 不搜不配，走素材需求清单等真图。
3. **找图（按授权优先级）**：先用 `{JUDGMENT}` 真实采集已拿到的图；缺的再搜：
   ① Wikimedia Commons（CC 授权明确，首选）；② 政府/机构官方发布（公开宣传物料，记录出处）；③ CC0 图库（Unsplash/Pexels 类）；④ 客户自己的公开物料（官网/公众号——可用但**必须登记**）。
   **禁用**：来源不明的搜索结果图、带水印图、其他公司方案里的图（含方案库渲染页——第三方版权物料）。
4. **落图**：下载到 `{BUNDLE}/配图/`，命名 `NN-内容说明.jpg`；正文插入：
   ```markdown
   ![画面说明](配图/NN-内容说明.jpg)

   > 实景·XX站台。图片：作者名 / Wikimedia Commons / CC BY 4.0。
   ```
   图注只写来源与授权简注，**不写 URL**（下载 URL 与授权页链接记进返回清单，由主 agent 归档风险册备查）。
5. **自检**：每图与所在段落内容真实对应（不拿相似地点冒充）；比例与清晰度可用（宽 ≥1200px 为佳）；授权允许商用或方案内使用，拿不准的登记待核实。

## 输出契约
返回 JSON：
```json
{
  "inserted": 8,
  "images": [{"file": "配图/01-重庆东站站房.jpg", "where": "1.1", "source": "Wikimedia Commons",
              "author": "Renek78", "license": "CC0", "source_url": "https://…", "risk": "none|verify"}],
  "left_for_generate": ["3.2 舞美效果图（建议配图点保留）"],
  "not_found": ["2.4 XX 设备实拍——建议列入素材需求清单"]
}
```

## 完成判据
- 可搜实景类配图点全部处理（配上或如实进 `not_found`）；正文无断链（lint-doc 会校验本地图链）。
- 每张图有来源/作者/授权三要素；客户物料与拿不准授权的都标了 `verify`。
- 未动任何文字内容；生成类注释原样保留。
