# Task 0b — 方案卡（库内方案编译）

你读一份方案库里的历史方案（已抽取的文本），把它压缩成一张**方案卡**——"这份方案值得偷师什么"。卡是跨标复用的资产：这次编好，以后每个相关标都直接读卡不重读原文。像编实体不像做摘要：**消化后的判断，不是内容罗列**。

占位变量：`{LANG}` · `{TEXT_DIR}` 抽取文本目录 · `{CARD_PATH}` 卡片写入路径 · `{SOURCE_META}`（原文件路径/板块猜测/年份）· `{TMPDIR}`。

## 卡片结构（写入 `{CARD_PATH}`）

```markdown
# 方案卡：<从内容里读出的方案标题>

- 来源：<相对路径> · 板块：<六板块之一或组合> · 年份：<读出或猜测> · 质量：金/银/铜/淘汰
- 客户与项目：<一句话——什么客户、什么标的>
- 核心主张/创意：<它靠什么赢；一句能复述的话；没有明确主张就如实写"无主张，纯响应">

## 值得偷师的（≤5 条，每条一句判断 + 定位）
- <结构打法/创意机制/包装手法/报价策略/内行细节——写"为什么好"，不是"有什么">

## 内行颗粒（可迁移的专业细节）
- <报价结构、工艺参数、平台口径、审批流程等——标注出现位置>

## 关键页码（图的入口）
- <核心创意/KV：第 X 页 · 分镜/流程表：第 Y-Z 页 · signature 级版面：第 W 页——按 MD 里"第 N 页"标注；需要看图时 `$PY tools/prop_tools.py library-pages --file <path> --first X --last Z` 渲染，缓存复用>

## 别学的
- <它做得差的地方，一句即可；没有就删本节>

## 使用边界
- 来源与授权不明的文案、客户数据、案例事实**不得迁移**进新方案；只参考结构、打法与颗粒。
- 渲染页图片是第三方版权物料：**只作内部参照与生成侧风格参考（style_reference），绝不直接进递交稿或 PPT 成品**。
```

## 质量评级口径
- **金**：核心创意过互换测试、结构火力分布清楚、执行有内行颗粒——值得提名晋升 `references/exemplars/`（在卡里写一行提名理由，最终由用户审定）。
- **银**：有可偷师的局部（某章打法、某类颗粒），整体平庸。
- **铜**：只有结构参考价值。
- **淘汰**：套话堆砌/纯模板——卡里写一句"为什么淘汰"，防止以后重复抽取。

## 红线
- 卡是内部资产，写判断可以直白（"第三章纯凑字数"）。
- 不复制原文超过一句的连续文案进卡。
- 拿不准客户/年份就标"猜测"，不编造。

## 返回
JSON：`{"card": "<CARD_PATH>", "quality": "金|银|铜|淘汰", "sectors": ["…"], "nominate_exemplar": false, "one_line": "这份方案一句话"}`。
