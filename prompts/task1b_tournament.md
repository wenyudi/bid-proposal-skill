# Task 1b — 创意锦标赛

一个方案 90% 的命运在创意收敛这一步就定了，文笔救不了平庸的创意。所以这里把最多的算力花在想创意上：并行发散 → 对抗淘汰 → 发展幸存者 → **用户从发展后的创意里选一个**。主 agent 按 `{ROLE}` 派发本文件，各 agent 只做自己角色的事。

占位变量：`{LANG}` · `{ROLE}` = ideate | kill | develop | onepager · `{JUDGMENT}`（Task 1 的 `_研判.md` 拆解部分 + JSON 索引）· `{LENS}`（ideate 专用）· `{CANDIDATES}`（kill/develop 输入）· `{PICKED}`（onepager 输入：用户选中的 concept brief）· `{TMPDIR}`。

制胜轴适配：创意制胜标跑"创意锦标赛"；管理制胜标同一机制降档为"主张锦标赛"——镜头换成机制/可靠/成本结构/风险兜底，四问中"截图测试"换成"复述测试"（决策者能否一句话向上级转述）。混合标以主轴为准。

## ROLE = ideate（并行 6–10 个，各持一个镜头）

从 `{LENS}` 单一镜头出发（outcome / experience / asset / contrarian / 文化母题 / 地缘独占 / 行为摩擦 / 机制可靠……由主 agent 分配，一人一个），交 2–3 个候选创意。**只对本镜头负责，大胆、具体、别自我审查**——淘汰是 killer 的活，不是你的。

每个候选：
```json
{"idea": "一句话创意", "tension": "它回应客户的哪个真张力",
 "causal": "为什么这个创意能解这个张力（因果，不是愿景）",
 "sketch": ["可执行雏形：三个具体动作"],
 "monopoly": "独占依据——为什么换一家公司/换一个客户就不成立"}
```
返回 JSON 数组。禁止：行业通用套路（"打造矩阵""全域传播"）、没有独占依据的候选。

## ROLE = kill（并行 2–3 个，对全部候选投票）

对 `{CANDIDATES}` 逐个过四问，每问 0–2 分：
1. **互换测试**：换成竞争对手/换一座城市，这个创意还成立吗？（成立=0 分）
2. **截图测试**：普通人刷到会截图/转发/@朋友吗？（管理制胜标改问：决策者能否一句话向上级转述？）
3. **内行测试**：做过这行的人会觉得可行，还是笑话？（预算量级、审批、平台规则常识）
4. **地板兼容**：它会不会伤合规覆盖、逼出无法兑现的承诺？

返回 JSON：每候选 `{"id", "scores": [n,n,n,n], "total", "verdict": "kill|keep", "one_line": "一句致命理由或最强价值"}`。**默认怀疑**：给分吝啬，keep 不超过 4 个。

## ROLE = develop（每个幸存创意一个 agent）

把幸存创意发展成一页 concept brief（Markdown，≤600 字）：
- 创意一句话 + 十秒记忆句候选
- 推导链：张力 → 创意 → 表达 → 执行 → 证明
- signature 设想（这个创意的"最清晰一页"长什么样）
- 三个最具体的执行动作（含责任/时点雏形）
- **最强反对理由**（自己写，写到能说服人放弃的程度）
- 需要哪些真实素材才能立住（对齐 Task 1 素材需求清单）

## ROLE = onepager（用户选定后，单个 agent）

以 `{PICKED}` 为准，产出完整制胜一页纸续写进 `{TMPDIR}/_研判.md`：
- 核心主张 + 十秒记忆句（逐字定稿）/ 推导链 / 拿分打法（地板怎么保、天花板怎么顶）
- 被淘汰创意各留一句为何不选（含用户未选的发展稿）
- 逐章骨架表：章号 | 标题（句式多样）| 独有贡献 | 认领评分项 id | 深度取向 | 体裁基调(论证/表格/朴素) —— 巅峰章 = 创意所在章，火力明显倾斜；打包类 floor 项归入"投标文件编制与递交"章
- **素材分配表**：每个论据/案例/数据/合规硬指标 → 唯一宿主章；合规硬指标指定底盘表宿主章
- 唯一 signature 主亮点 / 叙事选择（自 `narratives.json` 按制胜轴与标型选，写理由）
- 回填 `_score-table.json` 各项的 `claimed_by_section`

返回 JSON 索引（title / recall_line / narrative / signature / sections[] / open_fabrications[]），格式同 v4 Task 1 输出契约。

## 主 agent 编排（写在这里免查）
1. 按制胜轴选 6–10 个镜头并行派 ideate → 汇总 ≥12 候选（去重同质创意）。
2. 并行派 2–3 个 kill → 多数决合并，幸存 2–3 个（全灭则换镜头重发散一轮，最多两轮；仍全灭 → 如实告知用户"没有过硬创意"并展示最高分候选，不硬凑）。
3. 每个幸存者派 develop。
4. **唯一人工确认**：向用户展示评分表拆解摘要 + 素材需求清单 + 2–3 份 concept brief（各含最强反对理由），问"按哪个写？"。`-auto` → 按 kill 总分自动选，登记 assumed。
5. 派 onepager 定稿一页纸。

## 完成判据
- 候选 ≥12、幸存 ≤3、每个幸存者有发展稿与最强反对理由。
- 用户（或 -auto）明确选中一个；一页纸各字段齐全；每个评分项被且仅被一个合理章节认领；记忆句逐字定稿。
