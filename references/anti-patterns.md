# 反模式与失败归因

本文件不是机械禁词表，只服务复核（rival / style lens）与失败复盘，不进生成侧。术语只有在删掉后仍留下对象、机制、证据与结果时才有意义。命中一个词不自动判错；整句经不起追问才重写。

## 具体坏句
| 坏句 | 根因 | 必须回答的重写问题 |
|:---|:---|:---|
| "以创新驱动赋能项目高质量发展。" | 没有对象和因果 | 谁发生什么变化？靠哪一动作？ |
| "构建多维传播矩阵，形成全域触达。" | 渠道清单冒充策略 | 每个渠道承担哪一个不同决策任务？ |
| "打造内容生产、传播、反馈的闭环。" | 流程名词冒充机制 | 反馈由谁在何时改变下一轮什么？ |
| "全面提升品牌影响力和美誉度。" | 结果不可检查 | 针对谁、改变何种判断、用什么口径观察？ |
| "整合优质资源，实现 1+1>2。" | 未证明的资源与数学修辞 | 哪些已确认资源以什么组合产生增量？ |
| "依托专业团队和丰富经验保驾护航。" | 公司自夸且可互换 | 哪个已核验角色承担哪项责任和验收？ |
| "通过线上线下一体化提升用户体验。" | 没有真实摩擦点 | 用户在哪一步受阻，整合后少做什么？ |
| "建立长效机制，沉淀数字资产。" | 未来名词替代交付 | 本合同期交出什么、归谁、如何复用和验收？ |

高风险套话："赋能、生态、闭环、矩阵、全域、多维、抓手、引擎、焕新、聚势"。它们可以出现，但同句或紧邻内容必须能找到：具体对象、变化机制、项目依据、责任/时点、可检查结果。缺两项以上，优先整句删除而非替换同义词。

## 生成稿八种"AI 味"病灶（2026-08 三份真实稿复盘）
用户判"不能直接递交"的三份生成稿（轨道引流/银行贵宾活动/标牌制作）复盘所得，全部经原文计数证实。复核见到即报：
| 病灶 | 实测规模 | 识别特征 |
|:---|:---|:---|
| 口号复读机 | 记忆句原句 3/7/9 次 | 整句加粗独立成段反复出现，各章还配"这句话的含义是…"式阐释 |
| 论据跨章重写 | 同一先例 5 章各讲一遍，数字都复述 | 并行分章各自为战；同一案例/数据被多章完整展开 |
| 需求原文回声 | 同一合规句最多抄 23 遍 | 甲方要求原文当填充物逐章复抄，只有一次算应答，其余是翻页成本 |
| 章尾接力棒 | "本章已…下一章将…" 5–8 处 | 各章作者向彼此喊话而非向甲方说话，拼装痕迹外露 |
| 章节导览表 | 综述开头"第X章回答什么｜最强证据"矩阵 | 向读者解说文档结构，而非解说项目 |
| 免责外显 | "拟议示例/须确认/不代表历史工单"13–32 处 | 先声明"全是编的"再给小数点级假实测值，两头坏处全占 |
| 假精确 | 91 项报价全等于限价×0.88；ΔE00=1.7 | 同一公式批量生成数字、编造精度冒充履约证据，计算器抽三行即戳穿 |
| 修辞过密+自我播报 | 加粗 174 处；"条条硬/足以定案"式报幕 | 每两三段一个 keynote 警句，格式对仗五连排比命名，训话甲方 |

矫枉过正的第二轮病灶（同一稿"去 AI 味重写版"复盘）：修掉雄辩体后摆向另一个失败模式——
| 病灶 | 实测规模 | 识别特征 |
|:---|:---|:---|
| 无人称报告腔 | "我们/我方"0 次、"贵方/您"0 次 | 删元话术时把说话的主体一起删了；通篇第三人称说明文，没人在说、没说给谁听，感染力归零 |
| 段尾逐段升华 | "每一X，都Y"式点题收尾 8+ 处 | 每段 3–5 行等长、段尾必落意义，平滑到催眠，没有一个短句自然段 |
| 占位腔免责 | "一席某某类账号""邀约确认后锁定"×4 | 实名闸门被理解成空转席位描述；该给画像+真实公开对标例，免责统一说一次 |
| 图注免责+工具痕迹 | "AI 示意"20 处、"非真实发布/无真实数据"5 处 | 把内部真实边界印在递交稿脸上；图注只说明画面内容，边界进风险册 |
| 口号变本加厉 | 母命题 13 次（重写前 3 次） | 统一主张 ≠ 复读主张；片名、章标题、引用块、加粗独立段都在数 |

生成侧的对应规矩在 `writing-patterns.md`（全案只讲一次/有人在说话/节奏与感染力/修辞密度红线/虚构闸门）；词面铁证由 `tools/prop_tools.py lint-doc` 兜底，声线终审由 `prompts/task2c_polish.md` 主编收口，这里供 lens 抓语义层残余。

## 三类主失败
一次不满意只选一个主失败，可附次级标签；先修最上游根因，再看下游问题是否自然消失。
- **`strategy_hollow` 策略空洞**：洞察复述标书；主张可用于任何客户；互换测试通过；章节再漂亮也没有选择。回到一页纸重选主张（Task 1），不让 writer 润色掩盖。
- **`throughline_break` 主线断裂**：一页纸成立，但某章无法说明如何支撑主张；策略、创意、执行变成三组并列清单；综述强于正文。修该章的独有贡献与前后交接，重写该章。
- **`cliche_style` 文风套话**：底层逻辑基本正确，但正文被"赋能、矩阵、闭环、全面提升"覆盖，删掉术语后没有实物。对具体句子重写，不改主张语义。

## 将失败变成品味资产
每次真实使用后保存：场景、原始坏句、一种主失败、为何失效、改后版本、客户/评审反馈、是否可推广。没有反馈的改写只算候选教训；经人工确认后，才把短小对照提升进本文件或 `contrast-examples.md`。不要把私密原文、未授权案例或一次中标结果直接固化为通用规则。
